## errors-1. [high, wire-mismatch] CONFIRMED: A base URL with a path prefix is silently discarded: URI.resolve replaces the whole path

- Java: `/Users/jim/src/typesafe-client/typesafe-client/src/main/java/software/sava/typesafe/TypeSafeClientImpl.java:75`

The builder only warns in a doc comment (TypeSafeClient.java:75-76, "a value ending in a path segment is not what you want").
- Reference does: Both SDKs concatenate: Python `config.base_url + path` after `resolved_base_url.rstrip("/")` (config.py:57), and JS `const url = `${this.baseURL}${req.path}`` (typesafe-sdk-js/src/client.ts:351) after `stripTrailingSlashes`. Note FakeHttpResponse currently only carries a request-id header, so it needs a headers parameter before these cases can be pinned without a socket.
